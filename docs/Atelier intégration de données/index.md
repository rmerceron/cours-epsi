# Atelier intégration de données

Module présenté par Antoine LUDWIG (A.L.I.C.E Développement Web).

**Objectif du module** : Comprendre l'architecture d'un Système d'Information Décisionnel (SID) et maîtriser les processus ETL pour l'intégration de données.

## Sommaire du module

1. **Architecture** d'un Système d'Information Décisionnel (SID)
2. **Alimentation** et intégration de données
3. **Mise en œuvre** pratique
