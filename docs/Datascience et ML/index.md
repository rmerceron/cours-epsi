# Data Science & Machine Learning

Module présenté par Jean-Claude Houbart.

**Objectif du module** : Devenir opérationnel sur un projet intégrant du Machine Learning.

## Sommaire du module

1. **Introduction** à la Data Science et aux outils (Python, Scikit-Learn, Jupyter)
2. **Arbres de Décision** et Random Forest
3. **Modèles d'ensemble** et Boosting
4. **Features Engineering** : préparer et enrichir ses données

## Notes de cours

| Cours                                                                              | Contenu                                                                                          |

| [Introduction](cours-0-introduction)                                               | Types de modèles IA, apprentissage supervisé, Python, NumPy, Pandas, Scikit-Learn                |
