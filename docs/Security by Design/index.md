# Security by Design

Module présenté par Youenn DUVAL.

**Objectif du module** : Intégrer des mesures de sécurité dans toutes les étapes du cycle de vie du développement d'un produit ou d'un système, dès la phase de conception.

## Sommaire du module

1. **Introduction** à la Security by Design
2. **Méthodologies et modèles** de sécurité (STRIDE, RMF, OWASP, Zero Trust)
3. **Sécurité dans le projet** : cycle de vie, développement, DevOps, organisation, RGPD
4. **Concepts et failles techniques** (SOP, CSP, XSS, SSTI, IDOR, etc.)
5. **Focus OWASP Top 10** : les 10 vulnérabilités les plus critiques
